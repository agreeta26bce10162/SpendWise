# SpendWise

## A Personal Expense Tracking and Budget Management System

### Overview

SpendWise is a simple Python-based system for managing personal income and expenses. It helps users record transactions, manage a monthly budget, analyze spending, calculate savings, and generate monthly reports.

### Features

* Add income
* Add expenses
* View transactions
* Manage monthly budget
* Budget alerts
* Spending analysis
* Savings calculation
* Monthly reports
* Edit transactions
* Delete transactions
* Search transactions

### Technologies Used

* Python
* Python IDLE
* GitHub

### How to Run

1. Download or clone this repository.
2. Open the `spendwise.py` file in Python IDLE.
3. Run the program using **F5**.
4. Select an option from the main menu.
5. Enter the required information.
